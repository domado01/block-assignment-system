# 작업장 조업도 / 블록 배정 시스템

블록 단위 생산 계획 데모 시스템.

- **Python** (`generate_excel.py`) — 1만 블록 + 15 작업장 합성 데이터 생성, 다단계 배정 로직 적용
- **React + Vite** (`web/`) — 월간 조업도 히트맵 · 작업장별 배정 현황 · 로직 관리 3탭 대시보드

## 빠른 시작

```bash
# 데이터 생성 (엑셀 2개 + JSON 2개)
python -X utf8 generate_excel.py

# 웹앱 실행
cd web
npm install          # 최초 1회
npm run dev          # → http://localhost:5173/
```

요구사항: Python 3.10+, Node 18+

## 화면 구성

| 탭 | 내용 |
|---|---|
| **월간 조업도** | 작업장(15) × 1~12월 히트맵, 조업도/능력/부하 토글, 작업장 상세 차트 |
| **작업장별 배정 현황** | 최종작업장 기준 작업장별 배정 블록 수/공수, 미배정 건수 |
| **로직 관리** | 배정 로직 플로차트 + 파라미터 편집 + 재배정 실행 + 저장 |
